# Dungeon Tower Defense

A dark fantasy Tower Defense game where you play as a necromancer defending your dungeon against waves of heroes.

## About

Dungeon Tower Defense combines traditional Tower Defense with roguelite-style build progression.

During each stage:

- Defeat waves of enemies.
- Earn **Souls** by killing enemies.
- Spend Souls to place defenses.
- Choose between random rewards to build your defenses.
- Survive increasingly difficult waves.
- Complete the stage to gain permanent progression.

Rewards obtained during a stage are temporary, while permanent upgrades carry over between stages.

## Current Status

**Prototype / Work in Progress**

The current prototype includes:

- Graybox dungeon level
- Wave-based enemies
- Increasing enemy difficulty
- Defense placement
- Enemy detection and targeting
- Basic combat
- Soul economy
- Dark fantasy visual direction

The project is currently focused on validating the core gameplay loop.
